\chapter{考察}\label{cha:Evaluation}
本研究では、テストケースの可視化を目的としたツール\tool{}を試作した。
本章では、評価実験を行い、\tool{}の有用性に関する評価を行う。
次に、\tool{}と関連研究を比較する。
最後に、\tool{}の問題点について述べる。

% \tool{}の有用性に関する評価
\section{\tool{}の有用性に関する評価}
\tool{}の有用性を評価するため、\tool{}を使用する場合と使用しない場合で、
テストケースの抜けや不備または過剰箇所の発見にかかる時間に対する実験を行う。

\tool{}を使用する場合では、
\tool{}が出力したTCVダイアグラム(\ref{sec:testcase_visualization_diagram}節参照)を確認し、
被験者が全てのテストケースの抜けや不備または過剰箇所を見つけるまでにかかった時間を、発見時間として計測する。
\tool{}を使用しない場合では、
CSVファイルに記述した要求仕様書とテストスイートを確認し、
被験者が全てのテストケースの抜けや不備または過剰箇所を見つけるまでにかかった時間を、発見時間として計測する。

実験の事前準備として、要求仕様書とテストスイートの組を2つ用意した。
1つ目は、「閏年判定システム」に関する要求仕様書とテストスイートの組である。
具体的には、図\ref{fig:reqspec}に示した要求仕様書と、図\ref{fig:testsuite_1}および図\ref{fig:testsuite_2}に示したテストスイートの組である。
以降、この要求仕様書とテストスイートの組を、組$\alpha$と呼ぶ。
2つ目は、「成績付けシステム」に関する要求仕様書とテストスイートの組である。
用意した要求仕様書を図\ref{fig:exp_reqspec_b}に、テストスイートを図\ref{fig:exp_testsuite_b1}、図\ref{fig:exp_testsuite_b2}、図\ref{fig:exp_testsuite_b3}に、それぞれ示す。
以降、この要求仕様書とテストスイートの組を、組$\beta$と呼ぶ。
組$\beta$の要求仕様書とテストスイートに対して、\tool{}が出力したTCVダイアグラムを図\ref{fig:tcv_seiseki2}に示す。

なお、組$\alpha$および組$\beta$には、それぞれテストケースの抜け箇所を1件、不備箇所を1件、過剰箇所を2件、合計4件を意図的に含めた。

実験に参加する被験者は、宮崎大学で情報工学を専攻する4人(以降、被験者A〜Dと呼ぶ)の学生である。

実験の手順を、以下に示す。
\begin{enumerate}
    \item 組$\alpha$に対する作業を行う。
    \begin{itemize}
        \item 被験者A、B\\
        被験者A、Bは、\tool{}が出力したTCVダイアグラムを確認し、
        テストケースの抜けや不備または過剰箇所を見つける。
        \item 被験者C、D\\
        被験者C、Dは、CSVファイルで記述した要求仕様書とテストスイートを確認し、テストケースの抜けや不備または過剰箇所を見つける。
    \end{itemize}
    \item 組$\beta$に対する作業を行う。
    \begin{itemize}
        \item 被験者A、B\\
        被験者A、Bは、CSVファイルで記述した要求仕様書とテストスイートを確認し、テストケースの抜けや不備または過剰箇所を見つける。
        \item 被験者C、D\\
        被験者C、Dは、\tool{}が出力したTCVダイアグラムを確認し、テストケースの抜けや不備または過剰箇所を見つける。
    \end{itemize}
\end{enumerate}

表\ref{tb:exp_result}に、テストケースの抜けや不備または過剰箇所の発見時間についての実験結果を示す。

表\ref{tb:exp_result}に示すように、組$\alpha$に対して\tool{}を使用した場合、
テストケースの抜けや不備または過剰箇所の発見にかかる時間を、4分 28秒(81.5\%)削減できた。
また、組$\beta$に対して\tool{}を使用した場合、
テストケースの抜けや不備または過剰箇所の発見にかかる時間を、3分 54秒(80.7\%)削減できた。
以上の結果から、\tool{}が出力するTCVダイアグラムは、
テストケースの抜けや不備または過剰箇所の発見にかかる時間を削減することができ、
テストケースの可視化に有用であると考察する。
